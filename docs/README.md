# Documentation

This folder contains the official project documentation for LLM EaaS.

## Files
- PROJECT_OVERVIEW.md: What the platform is, why it exists, core capabilities, and business value.
- FREE_TIER_DEPLOYMENT.md: End-to-end zero-cost deployment guide using Render, Vercel, and Groq.
- OPERATIONS_CHECKLIST.md: Post-deployment runbook for verification, monitoring, and incident response.
- INTERVIEW_DEMO_SCRIPT.md: 10-line and 60-second pitch versions for demos and interviews.

## Recommended Reading Order
1. PROJECT_OVERVIEW.md
2. FREE_TIER_DEPLOYMENT.md
3. OPERATIONS_CHECKLIST.md
4. INTERVIEW_DEMO_SCRIPT.md

## Notes
- This docs set is designed for practical execution and quick onboarding.
- All guides target low-cost validation first, then production hardening.
